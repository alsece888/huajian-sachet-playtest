## 本版修改
按照《香包游戏优化》12 条建议更新，2026-09-16。

- 第几天、08:00—18:00 营业时间、银子；一日现实 3 分钟。
- 顾客陆续到店，订单显示红/蓝袋型与 1—4 味配料图；等待时改变表情。
- 玫瑰、丁香、薄荷、桂花开放。每篮取五次变空，点五次补货；未开放香料为空篮。
- 多味香料同称，整批拖入研磨或蒸制。
- 研磨自动进行，5 秒进入绿区后点击完成。错过可等下一轮。
- 蒸制点击移动绿区，每次命中增加 20%，达到 100% 完成。
- 每批得到两份，拖到同一香盘。香囊也拖到盘上，再拖成料入袋；一份足够装一袋，另一份留盘。
- 点击装好料的香囊，沿袋口画线系紧，再拖给顾客。
- 轻触或悬停器具、成料、香囊可查看配料；不要的东西拖入废料桶。
- 正确订单支付 16＋每味 8 两；错误订单收走香囊、露出不满表情，只付 2 两。交付显示收入。
- 收铺后可开启下一天，工作台清空、库存补满，银子保留。
- 设置菜单与切到其他页面暂停时间；系带时营业继续。
