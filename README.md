# 花间香铺 · 外部试玩
移动端香囊厨房经营原型，外测版本 V5.1。

## 发布
在 GitHub 创建 huajian-sachet-playtest 仓库，上传本目录内容。
进入 Settings → Pages → Deploy from a branch，选择 main 分支的 /docs，保存。
GitHub 完成构建后，在 Pages 页面提供公开试玩地址。

## 测试方式
手机竖屏打开网页，阅读说明后点击“开始试玩”。
重点测试原料拖放、长按研磨、自动蒸制、两份入同盘、画线绑袋、订单交付与顾客情绪。
遇到问题：说明手机型号、浏览器、操作步骤、预期/实际结果，并附截图。
页面右上角菜单可下载测试记录，请将文件与反馈一起交给组织测试的人。
测试记录仅在点击下载时保存到本机，不会自动上传。

## 当前范围
玫瑰/丁香两种单料配方；红色香囊；最多三位客人。
客人每 18 秒陆续来，耐心 65 秒。称量 1 秒，研磨/蒸制各 5 秒。
不包含登录、云存档、付费与补货。刷新页面重新开始。

## 维护
网页源文件位于 docs。规则检查：npm test（Node 20 或以上）。
插画素材为项目生成资产，仅随本项目试玩提供；未授予独立素材再分发许可。
